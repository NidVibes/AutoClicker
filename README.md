# ⚡ Pro Python Auto-Clicker GUI

A lightweight, modern desktop auto-clicker built with Python, Tkinter, PyAutoGUI, and Pynput. It features a customizable Clicks-Per-Second (CPS) slider, dark mode UI, and global hotkeys for hands-free control.

---

## ✨ Features

- **Customizable CPS:** Adjust clicking speed dynamically from 1 to 50 Clicks Per Second.
- **Global Hotkeys:** 
  - `F6`: Toggle Start / Pause
  - `F7`: Close application cleanly
- **Safety First:** Built-in `pyautogui` fail-safe mechanism (slam mouse into any screen corner to abort).
- **Dark Mode UI:** Built using native Tkinter with asynchronous threading so the interface never freezes.
